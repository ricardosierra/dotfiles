# Global Anti-AI Git Hooks

The dotfiles include out-of-the-box global Git protection against forced AI co-authorship and trailers injected by agents (Cursor, Claude, Grok, Codex, OpenAI, Gemini, Copilot, etc.).

---

## How It Works

During dotfiles installation (`dotfiles install` or `init/15_git.sh`), Git is configured globally with:
* `core.hooksPath = ~/.git_hooks`
* `init.templateDir = ~/.git_template`
* `~/.config/husky/init.sh` (for Husky-enabled repositories)

### The 3 Layers of Defense

1. **`pre-commit` (Identity Check)**:
   Prevents commits where `GIT_AUTHOR_NAME` or `GIT_AUTHOR_EMAIL` represents an AI agent. Author must always be a real developer.

2. **`commit-msg` (Automatic Sanitization)**:
   Before the commit SHA is calculated, it inspects the commit message and automatically removes lines such as:
   * `Co-authored-by: Cursor <cursoragent@cursor.com>`
   * `Co-authored-by: Claude <noreply@anthropic.com>`
   * `Co-authored-by: Grok <grok@x.ai>`
   * `Made with [Cursor](...)`
   * AI badges and attribution trailers (`Generated by ...`, etc.)

   *Note*: Uses `clean_commit_msg.py` (Python 3) with an automatic POSIX `grep`/`sed` fallback if Python is unavailable.

3. **`pre-push` (Push Guard)**:
   Scans all outgoing commits before pushing to remote repositories. If any commit contains AI trailers or authorship, the push is immediately blocked.

## Multiplatform Support

* **macOS**: Configured automatically via `dotfiles install`.
* **Linux (Ubuntu, Debian, Fedora, Arch, etc.)**: Configured automatically via `dotfiles install`.
* **Windows (Git Bash / MSYS / WSL)**: Configured automatically via `dotfiles install`.
* **Windows (PowerShell)**: Can also be installed directly by running:
  ```powershell
  powershell -ExecutionPolicy Bypass -File scripts\install_git_hooks.ps1
  ```

---

## Compatibility

* **Local Hooks**: If a project defines its own `.git/hooks/`, the global hooks delegate to them after sanitization.
* **Husky**: Repositories using Husky (v7+) automatically load `~/.config/husky/init.sh` before running project hooks, providing zero-touch protection without modifying tracked repository files.
